# 🐰 Conejo acariciable

Mini juego en un solo archivo HTML, sin dependencias.

- Elegí la raza: Holland Lop, Enano, Angora, Leonado o Gigante.
- Cambiale el color y agregale manchas.
- La mano es el cursor: pasala por el conejo y el pelaje se mueve.
- Dale una zanahoria: acercala a la boca y se la come.
- Funciona con mouse y con el dedo en el celu.

## Cómo probarlo

Abrí `index.html` en el navegador.

## Publicarlo con GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)`.
